# Buget1 - ClearMint Ledger

This repository contains ClearMint Ledger, a production-ready budgeting web app built with Node.js, Express, SQLite, and a responsive vanilla JS frontend. The application lives in the `ClearMint-Ledger` directory.

## Running locally
```bash
cd ClearMint-Ledger
npm install
npm start
```
Then open http://localhost:3000.
